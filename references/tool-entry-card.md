## 1. 使用边界与创作合同

本文件只用于网页工具入口卡、功能跳转图、工具 Banner、功能缩略图和点击导流卡。普通海报、详情页、社媒单图、场景资产和艺术创作不得自动套用。

入口卡不是完整说明页，而是一张负责 `识别功能 → 展示结果 → 激发点击` 的缩略视觉资产。优先级依次为：

1. 功能识别；
2. 结果吸引力；
3. 点击欲；
4. 与承载页面的视觉关系；
5. 单帧美学；
6. 放大后的细节丰富度。

不能只做一张漂亮但与工具功能无关的海报。用户明确指定平台画风时才继承；未指定时按目标人群、功能和结果自主定调，不自动模仿平台 UI。

## 2. 三秒功能识别

生成前和交付前都做三秒测试：

- 不读小字时能否识别功能？
- 能否看见功能处理后的结果？
- 缩小到实际卡片尺寸后，主体、结果与关键文字是否仍可读？
- 用户能否想象自己的素材经过该工具会得到什么？

三秒测试不通过时，优先重写功能证据和视觉层级，不增加更多装饰或说明文字。

## 3. 功能到视觉证据的映射

先写清 `输入 → 处理 → 输出`，再选择最短、最直观的画面证明。常见映射：

| 功能 | 首选视觉证据 |
| --- | --- |
| AI 生图 | 文字、普通照片或参考素材 → 明显更完整的目标视觉 |
| 背景移除/替换 | 原背景 → 透明或干净主体 → 新使用场景 |
| 拼图 | 多张独立照片 → 清楚网格；基础网格＋多种创意模板 |
| 滤镜/风格转换 | 同一主体的原始状态 → 明显但可比的风格结果 |
| 图片编辑 | 明确局部问题 → 可见修改 → 完成态 |
| 视频生成 | 静态输入或提示 → 具有明确运动、镜头或时间变化的成片瞬间 |

一张图优先证明一个主功能，最多增加一个辅助能力。抽象能量、粒子、通用 AI 图标和科技光效不能替代功能证据。

## 4. 完成态与点击欲

入口卡不只展示“能做”，还要展示“值得做”。完成态应让目标用户感受到可发布、可投放、可售卖、可分享或可保存的结果价值。

按功能选择一种主结构：

- **结果主体型**：适合 AI 生图、电商成片和背景替换。完成态占主要视觉面积，输入素材只作辅助证明。
- **模板集合型**：适合拼图、滤镜和模板工具。一个主要结果负责识别，其他结果以不同结构证明丰富度，可被画面边缘部分裁切。

输入与输出必须保持同一人物、商品或素材身份；提升来自构图、光影、色彩、场景、材质和编辑能力，而不是偷偷更换主体。

## 5. 缩略图构图与裁切

先按最终缩略尺寸设计，再补充放大细节：

- 保留一个明确视觉中心和一条阅读路径；
- 主要功能证据使用位置、尺度、色彩或清晰度优势；
- 背景与次要模板降低细节频率，不与主结果抢焦点；
- 重要人物、商品、功能词和对比边界远离高风险裁切区；
- 模板集合允许外围卡片不完整呈现，用裁切暗示数量和延展；
- 留白可以承担分隔、呼吸、引导、对比和安全区，不要求机械填满。

“充分利用画面”指每个区域有职责，不等于每个像素都塞入元素。

## 6. 语义密度与装饰因果

画面中的主体、背景、道具、原料、液体、花朵、粒子、文字和留白，至少承担一项职责：

- 功能解释；
- 卖点或结果证明；
- 目标人群与使用场景；
- 情绪建立；
- 视觉引导与层级分离。

任何尺度突变、环境撕裂、能量、液体、悬浮或结构重组，都必须能从商品材质、成分、功能、使用效果或创作过程推导。若替换成任意产品仍无需改变，说明它大概率只是通用噪声。

## 7. 多格内容与动作去重

拼图、模板墙、故事板和多格入口卡在生成前建立动作/信息矩阵。每个照片格必须新增一种可辨认的信息，不得用同一动作、同一表情、同一合照或同一事件的近似角度机械填充。

优先交替：

- 人物关系照；
- 行为动作照；
- 环境建立照；
- 商品、食物或生活物件特写；
- 宠物或生活细节；
- 远景、俯视或空镜。

禁止连续出现多张坐着聊天、举杯、自拍、看镜头、同向行走或同一动作换景别。需要同一群人保持故事连续时，锁定身份与时间，同时让每格动作、景别和信息职责不同；无关卡片使用不同人物，避免克隆脸。

## 8. 人物、花字与曝光

人物入口卡默认使用可读的正面或三分之四自然光。不同肤色保持真实层次，不因统一提亮而漂白，也不能为了夕阳、胶片或氛围让脸发黑、发灰、偏橙或五官消失。

社媒花字只在目标人群和功能需要时使用：

- 主功能词最多一个；
- 辅助情绪词通常 1–2 个；
- 放在白色分隔带、天空或低信息区域；
- 不遮脸、不遮商品、不破坏功能对比；
- 长文、品牌 Logo 和精确营销文案优先确定性后期合成。

## 9. 商品权威性与高级感

商业高级感由产品权威性、成像质感、色彩系统、光影材质、场景陈列和克制后期共同构成。不能只依赖黑金、大理石、深色背景或“奢华”词汇。

用户允许自由选品时，优先选择有设计完成度、市场辨识度和场景适配性的旗舰款、最新款、经典代表款或品类代表产品。涉及真实品牌的“最新/旗舰/排名”属于需核实事实；没有可靠资产时使用无 Logo 的高完成度概念商品，不得冒充真实品牌型号。

入口卡中的商品完成态应达到可投放的商业摄影水平：商品结构准确、主色可信、材质反射合理、背景符合价格带和使用场景，输入到输出的提升足够明显。

## 10. 交付前验收

- 三秒内是否识别功能与主要结果？
- 缩小后是否仍有一个明确视觉中心？
- 输入、处理和输出是否逻辑对应？
- 用户是否能想象自己的素材得到类似结果？
- 每个元素是否有功能、卖点、情绪或层级职责？
- 高级感是否同时来自产品、色彩、光影、材质和场景，而非单一风格词？
- 多格内容是否动作去重、信息互补、人物不克隆？
- 人脸是否明亮可读且不同肤色真实？
- 外围裁切是否增加延展感，而非切掉主要功能证据？
- 是否出现用户未要求的 AI 徽章、闪光图标、加号、伪按钮、右下角黑色标志、水印或平台 Logo？

任一核心项失败，先修正唯一主变量，再重新验收。
