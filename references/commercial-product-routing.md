## 1. 使用边界

本文件只用于电商、广告、种草、商品详情页、社媒商品封面和商业数字人。消费者决策知识决定应检查和证明什么，不等于商品事实；所有卖点仍服从 `product-preflight.md` 的证据边界。

## 2. 从消费者决策到图片模块

按以下顺序工作：

`品类 → 成交理由 → 头号犹豫 → 当前证据 → 主模块 → 可见证明 → 构图与互动`

一张图只承担一个主模块，必要时增加一个辅助模块。不要因为品类推荐六个模块，就把所有信息塞进同一画面。

## 4. 模块画面职责

- **Hero**：商品结构、正面和品牌识别最清楚，人物与背景不抢焦点。
- **Usage**：操作步骤、持握、接触面与可见结果真实，重点是“会不会用”。
- **Lifestyle**：使用后的生活体验与情绪；不替代功能证明。
- **Material/Texture/Fabric/Ingredient**：通过可信微距、断面、织纹、反射、折射或包装已确认信息呈现；不虚构成分。
- **Performance/Accuracy/Safety/Certification**：只有证据明确时启用；静态图优先展示可验证状态，精确数字和认证标志留给后期。
- **Dimension/Capacity/Fit/OnBody**：用人物、家具、桌面和空间建立相对尺度，避免假尺寸文字。
- **Trust**：干净专业的使用环境、真实接触、稳定商品结构、明确售后或认证素材；不能用凭空生成的徽章替代证据。
- **BeforeAfter/Comparison**：左右状态、主体、机位、光线和构图必须可比；无法证明的功效不启用。
- **Gift**：礼赠对象、包装、递送与仪式感服务商品，不让节庆装饰淹没产品。

## 5. 单图与图组选择

- 单张封面：Hero 为主，最多加入一个 Usage、OnBody 或 Lifestyle 证据。
- 三张图组：Hero → 核心证明 → 使用/生活方式。
- 六张详情图：Hero → 核心卖点 → 使用 → 材质/细节 → 尺度/适配 → Trust。

图组共享商品身份、色彩、比例和光影母规则，但每张图只解决一个消费者问题。
