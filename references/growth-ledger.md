# 林枫生图成长账本

## 使用规则

本账本保存经验的证据、适用边界和状态，避免把单次偶然偏好写成永久规则。执行中的精炼规则位于 `active-learnings.md`。

状态：`观察` → `候选` → `已验证` → `生效`，以及 `拒绝` / `退役`。

每条记录必须包含：

- 日期
- 原问题或失败现象
- 本次调整
- 因果理由
- 可复用规则
- 适用范围
- 例外/反例
- 证据次数与来源范围
- 当前状态

晋级标准：至少两次独立任务验证；或用户明确要求全局采用，且规则的因果关系、通用性和边界都清楚。未晋级经验只留在本账本，不进入 `active-learnings.md`。

禁止记录：私人信息、具体人物身份、一次性文件名、单个项目坐标、未验证猜测、没有理由的纯审美偏好。

## GL-001

- 日期：2026-08-06
- 原问题或失败现象：参考图优化时，风格或光影调整容易连带改变人物、家具、产品和机位。
- 本次调整：先建立不可变/可变约束卡，再生成。
- 因果理由：生成模型会把“优化”理解为整体再设计；没有逐项锁定时，结构约束容易被审美词稀释。
- 可复用规则：结构锁定优先于风格优化。
- 适用范围：人物、场景、产品和多参考图任务。
- 例外/反例：用户明确授权重新设计结构。
- 证据次数与来源范围：用户过往多类人物、室内场景和产品任务中反复出现。
- 当前状态：生效；原对应 AL-001，现迁移至 DP-01、DP-03。

## GL-002

- 日期：2026-08-06
- 原问题或失败现象：用户要求“重新生成”时，如果仍按原图局部优化，会保留上一版错误和旧像素逻辑。
- 本次调整：明确区分全新生成与局部编辑。
- 因果理由：两种任务的参考图使用方式不同；前者参考特征，后者保留像素和构图。
- 可复用规则：明确说从零重新生成时，旧图只承担参考职责。
- 适用范围：上一版失败后的重新生成、风格重建和全图再渲染。
- 例外/反例：用户要求只修某处或原构图/原像素保持不变。
- 证据次数与来源范围：用户在人物图和室内场景图任务中多次明确区分。
- 当前状态：生效；原对应 AL-002，现迁移至 DP-02。

## GL-003

- 日期：2026-08-06
- 原问题或失败现象：修正偏黄、过白或主体大小时，模型容易从一个极端跳到另一个极端。
- 本次调整：用相对幅度做单变量修正，并同时锁定需要保留的原调性。
- 因果理由：“减少”没有参照物时会被解释成彻底更换；保留项能限制修正范围。
- 可复用规则：对“稍微、减半、淡一点”等反馈采取保守相对调整。
- 适用范围：光线、色温、饱和度、尺度和空间扩展幅度。
- 例外/反例：原方案方向错误，需要完全替换。
- 证据次数与来源范围：用户在室内自然光、黄色调和主体尺寸修正中反复提出。
- 当前状态：生效；原对应 AL-003，现迁移至 DP-04。

## GL-004

- 日期：2026-08-06
- 原问题或失败现象：把“高清低噪点”直接写成 8K、极致细节或强锐化，容易得到塑料皮肤、伪 HDR 和暗部噪点。
- 本次调整：通过曝光、暗部、材质和细节预算控制清晰度。
- 因果理由：分辨率口号不能修复光线与纹理逻辑，反而会放大不自然的高频细节。
- 可复用规则：高清低噪点依靠可信成像，不依靠堆叠超清词。
- 适用范围：真人、场景、产品和电影感图片。
- 例外/反例：用户明确要求高锐数码视觉或微观纹理。
- 证据次数与来源范围：上传的 v4.0 框架与用户长期的高清低噪点要求一致。
- 当前状态：生效；原对应 AL-004，现迁移至 DP-21。

## GL-005

- 日期：2026-08-09
- 原问题或失败现象：带面部特写的角色四视图容易被模型理解为四位相似人物，导致正面、侧面、背面的脸型、体态、发型、服装或配饰漂移。
- 本次调整：建立固定版式，并把左侧正面面部特写设为唯一身份母版；右侧三个全身角度逐项复用身份与服装锚点。
- 因果理由：“保持同一个人”过于抽象；明确母版、角度和需复用的可见特征，能降低多主体生成时的身份分叉。
- 可复用规则：多视图必须服从唯一身份母版，所有视图只改变观察角度，不改变角色设计。
- 适用范围：用户明确要求生成的带面部特写四视图，以及明确指定为四视图的人物资产图和角色转面设定图。
- 例外/反例：不同年龄、不同造型、变装对比或多人对照板。
- 证据次数与来源范围：用户基于多次人物资产任务明确要求全局采用，规则具有清楚因果关系和通用边界。
- 当前状态：生效；原对应 AL-005，现迁移至 DP-07。

## GL-006

- 日期：2026-08-09
- 原问题或失败现象：真人角色图即使写了“超写实、4K、高清”，仍可能出现塑料皮肤、均匀假毛孔、玻璃眼、过锐边缘、服装纹理熔化和明显 AI 感。
- 本次调整：把真人感拆成镜头透视、曝光、皮肤色阶、微纹理、眼球、发际碎发、布料织纹、接触阴影和克制后期等可验证关系。
- 因果理由：分辨率与风格口号只描述结果，不约束真实成像；生理、材质和光学关系共同成立时，画面才更接近真实摄影。
- 可复用规则：真人感依靠成像与生理逻辑，不依靠堆叠高清词。
- 适用范围：真人定妆照、商业人像、人物资产图和真人角色四视图。
- 例外/反例：数字人、蜡像、CG、动漫或用户明确要求强美容修图。
- 证据次数与来源范围：用户基于长期真人资产图需求明确要求全局采用，且与现 DP-21（原 AL-004）的高清低噪点原则相互验证。
- 当前状态：生效；原对应 AL-006，现迁移至 DP-09。

## GL-007

- 日期：2026-08-09
- 原问题或失败现象：独立前向测试中，用户只要求通用四视图提示词且未提供人物身份，输出擅自补出了性别、族裔、年龄和具体五官。
- 本次调整：区分“通用模板”与“自由设计/直接生成”；前者保留身份锚点填写位，后者才允许创作身份。
- 因果理由：人物身份会实质改变最终资产，不属于模板任务中可随意补全的低风险缺口。
- 可复用规则：没有身份来源的通用人物模板不得擅自发明人口特征。
- 适用范围：人物四视图、定妆照、角色设定和人物资产提示词模板。
- 例外/反例：用户授权自由设计，或请求直接生成且接受合理视觉补全。
- 证据次数与来源范围：一次独立前向测试。
- 当前状态：候选。

## GL-008

- 日期：2026-08-09
- 原问题或失败现象：四视图专项的读取条件包含“角色设定图、人物多视图资产”等宽泛信号，可能把左侧特写、右侧三转面、白棚和自然站姿误套到不需要四视图的普通任务。
- 本次调整：把专项入口收紧为用户明确要求“四视图”或“带面部特写的四视图”；其他人物任务完整跳过该模块。
- 因果理由：四视图版式是特定交付结构，不是人物生图的普遍质量规则；宽泛触发会改变用户没有要求的构图与画布。
- 可复用规则：专项版式必须由明确的输出结构需求激活，不得仅凭题材相似自动套用。
- 适用范围：角色四视图模块的读取、提示词组织和直接生图。
- 例外/反例：用户虽未使用“四视图”一词，但明确描述了“一张脸部特写加正面、侧面、背面三个全身视图”的同等结构。
- 证据次数与来源范围：用户明确纠正并要求作为全局触发边界。
- 当前状态：生效。

## GL-009

- 日期：2026-08-09
- 原问题或失败现象：同一场景的主视图、反向机位和俯视图若分别自由生成，容易出现门窗换位、家具增删、空间镜像、光源方向变化和方位无法对应。
- 本次调整：新增按需激活的场景多角度模块；先完成单张主视图，再建立唯一空间母版、C1/C2 机位和东南西北方位，最后生成反向机位与俯视图。
- 因果理由：多角度场景的一致性依赖共享拓扑，而不是重复使用同一组风格词；主视图必须先成为空间事实来源。
- 可复用规则：场景多角度服从唯一空间母版，反向机位只改变观察方向，不镜像或重建场景。
- 适用范围：同一场景多角度图、正反打背景、反向机位图、俯视方位图和场景设定板。
- 例外/反例：普通单张场景图、重新设计空间、平行世界或不同时间状态。
- 证据次数与来源范围：用户明确要求作为可复用的全局专项模块，并明确限定为按需激活。
- 当前状态：生效；原对应 AL-007，现迁移至 DP-12。

## GL-010

- 日期：2026-08-09
- 原问题或失败现象：真实人物只凭“年轻、时尚、身材好”等宽泛描述直接生图，容易出现身份不符合预期、头身比异常、腿长漂移、肩胯失衡、手脚尺度错误和多轮返工。
- 本次调整：新增真人身份参数卡前置流程；首次生图先明确身份、核心气质、人口设定、五官、服饰与具体身材比例，再进入生成。
- 因果理由：人物生成的比例错误通常源于缺少可执行的解剖与体态锚点，而不是画质词不足；提前锁定参数可以减少模型随机设计。
- 可复用规则：首次真人生图先锁身份与身材比例，确认后再生成并在后续资产中复用。
- 适用范围：真人定妆照、全身图、人物资产、真人四视图和商业人像。
- 例外/反例：动漫或CG人物、无身份与连续性要求的远景路人，以及已有参数卡的同一人物后续镜头。
- 证据次数与来源范围：用户根据多次人物比例错误与返工经验明确要求作为全局工作流。
- 当前状态：生效；原对应 AL-008，现迁移至 DP-08。

## GL-011

- 日期：2026-08-20
- 原问题或失败现象：用户要求场景图“广角一点”以展示更多环境信息时，输出把需求机械翻译成焦段、房间尺寸、复杂空间拓扑和大量相机参数，偏离了场景资产的真实用途。
- 本次调整：把用于后续视频的场景图识别为场景母图，优先采用稍远的完整环境景别，覆盖更多可复用的空间特征；仅在确有必要时补充镜头参数。
- 因果理由：后续视频可能出现远景、镜头后拉和人物跨区域走位；母图若只呈现局部近景，未出现的空间会被视频模型随机补全，导致场景漂移。信息覆盖比参数堆叠更直接地降低这种随机性。
- 可复用规则：场景母图优先覆盖主要空间边界、固定陈设、出入口、活动区和前中后景关系；“广角一点”先按扩大信息覆盖理解，不机械等同于超广角镜头。
- 适用范围：视频场景母图、空场景资产、分镜背景、需要远近景变化或镜头扩展的参考图。
- 例外/反例：用户明确要求成片近景、人物情绪特写、商品特写，或局部细节本身就是唯一交付目标。
- 证据次数与来源范围：用户基于实际视频资产工作流明确要求全局采用，因果关系、通用性和适用边界清楚。
- 当前状态：生效；原对应 AL-009，现迁移至 DP-16。

## GL-012

- 日期：2026-08-23
- 原问题或失败现象：稳定视觉原则、模型经验和成长证据混在同一执行层，日常反馈缺少候选队列、语义去重、已验证与退役状态；继续追加会造成重复加载、单次经验污染和多账号分叉。
- 本次调整：新增视觉决策原则、学习系统、候选收件箱与退役记录；把原 AL-001 至 AL-009 的稳定规则迁入 DP 层，Active Learnings 只保留模型/平台限定经验；主文件只负责条件路由和优先级。
- 因果理由：稳定导演逻辑与易变模型经验的复核周期不同；证据层与执行层分离后，经验可以被保留，但只有成熟规则影响未来生成。
- 可复用规则：经验先作为带因果、范围、例外和证据的候选保存，经独立验证或用户明确批准后再进入正确执行层；被推翻的规则保留退役记录，不直接删除。
- 适用范围：本技能的日常复盘、规则更新、多账号证据合并及未来 GitHub 母版同步。
- 例外/反例：当前任务中的明确用户修正可立即用于当前结果，但不因此自动成为长期规则。
- 证据次数与来源范围：用户明确要求将补丁的视觉决策层与持续学习机制合并进本账号当前 Skill；现有成长账本提供历史迁移证据。
- 当前状态：生效，对应 `learning-system.md`、`visual-decision-principles.md` 与 SKILL.md 路由。

## GL-013

- 日期：2026-08-25
- 原问题或失败现象：网页工具入口卡多轮生成中，画面容易只追求漂亮而无法三秒识别功能；随机粒子、无因液体和 AI 徽章占用视觉空间；高级感被误解为黑金、深色或昂贵品类；拼图多格重复同一动作，人物曝光发黑，完成态缺乏点击价值。
- 本次调整：新增工具入口卡专项模块，并补充三秒识别、功能证据映射、语义密度、综合高级感、特效因果、缩略图裁切、非业务标志禁止、动作去重与旗舰产品事实核验。
- 因果理由：入口卡的最终职责是让用户在小尺寸下识别功能、理解结果并产生点击欲；每个元素必须服务功能、卖点、情绪或层级。商业高级感同时依赖产品权威性、成像、色彩、材质、光影和场景，而多格重复会降低模板丰富度与真实社媒感。
- 可复用规则：工具入口图先建立输入—处理—输出的可见证据并做三秒缩略测试；多格内容动作和信息去重；特效必须与主体存在因果；高级感按产品、成像、色彩、光影材质和场景五层验收；真实旗舰、最新与排名断言必须核实。
- 适用范围：网页工具入口卡、功能跳转图、工具 Banner、功能缩略图，以及需要展示输入到完成态的商业图片；高级感、特效因果和产品事实规则可用于其他商业生图。
- 例外/反例：普通艺术图、剧情图和场景资产不自动使用入口卡版式；用户明确要求纯抽象概念、指定平台徽章或特定暗色品牌系统时服从本轮要求；项目限定的 4:3、欧美年轻人和暖亮配色不写为全局规则。
- 证据次数与来源范围：同一入口卡项目内覆盖 AI 生图、背景移除、商品成片和拼图等多个功能任务；用户明确要求将因果清楚、边界明确的总结同步到本账号与 GitHub 母版。
- 当前状态：生效；对应 DP-24 至 DP-30、`tool-entry-card.md`、`product-preflight.md` 与 `commercial-product-routing.md`。
