# 林枫生图提示词框架｜High-Signal Prompt Compiler

本文件定义生图提示词的默认编译方式。目标不是“写得完整”，而是：**用最少、最精准的词，保留用户最强视觉意图，只补真正会改变结果的信息。**

## 0. 核心DNA

`保留强意图 → 锁必要事实 → 最小补充 → 污染审计 → 输出`

三条总原则：

1. **锁结果，不锁过程。** 先写最终想看到什么，不为显得专业自动规定焦段、比例、灯位、三角构图等实现方式。
2. **专业知识放后台。** 相机、光影、材质、空间、产品与人物知识用于判断，不等于全部进入Prompt。
3. **每句话都要有画面价值。** 删除后画面、动作、关系、光色、材质、文字或物理结果不变，就删除。

## 1. 用户原始意图优先

用户已经给出高信号视觉词时，尽量保留原表达或轻微整理，不把一句有效指令扩写成说明书。

高信号例子：
- 香水贴脸
- 闭眼自然笑
- 极近景
- 白色背景
- 蓝色大字
- 自然皮肤瑕疵
- 巨大前景压迫人物
- 产品完整清晰

这些词已经直接改变画面，不需要继续解释“脸向产品倾斜多少、手指如何包裹、主体占画面百分之多少”。

“高级感构图、时尚杂志感、真实棚拍、超现实奇观”等模型已有稳定视觉先验的概念可以保留一次。只有当结果不稳定、用户要求复刻，或该概念仍过于模糊时，才补 1–2 个可见特征。

## 2. 默认Prompt格式

### A. 简单单图｜默认

一段自然语言，通常按这个顺序组织：

`画面类型/主风格；主体 + 核心动作/关系；一个构图意图；环境/背景；关键光色/材质；必要文字/产品锁；少量高风险限制。`

示例结构：

```text
9:16高端时尚香水广告，真实明亮棚拍。年轻黑人女模特长发、闭眼自然微笑，手拿香水贴脸，人物与产品形成紧密特写；白色背景，明显深蓝英文排版，保留自然皮肤纹理。香水保持参考外观和真实手持比例，画面干净时尚。避免产品变形、塑料皮肤、英文乱码。
```

重点：不是固定模板，而是**最多只保留当前图真正需要的信号**。

### B. 中等复杂图

必要时分 2–4 个短块：

```text
【主体/关系】
【构图/环境】
【光色/质感】
【必要锁定/风险】
```

没有内容的块直接省略，不为了格式补废话。

### C. 高控制任务

只有以下任务才启用结构化详细字段：
- 跨图人物一致性
- 严格商品复刻
- 多主体复杂接触
- 场景拓扑/多角度
- 四视图/角色设定
- 局部编辑且保留区很多
- 用户明确要求完整参数化Prompt

旧24字段保留为**后台检查表**，不再作为普通单图默认外显格式。需要时按原顺序检查：相机/景别/景深、主体/身份/外貌/材质/动作、机位/空间、主辅光、色温/色彩、对比与高光阴影。

## 3. 信息价值判断

任何新增信息先过三档：

### 高价值｜默认保留
- 主体是谁
- 最关键动作/关系
- 产品/身份真源
- 一个核心构图意图
- 明显影响结果的背景/色彩/文字
- 当前最重要的光线方向或曝光状态

### 情境价值｜按需
- 焦段
- 精确机位
- 灯具/角度
- 主体占比
- 景深细节
- 前中后景拆分
- 复杂材质描述

只有它们能解决当前画面问题时才写。

### 低价值｜默认删除
- 第一/第二/第三视觉层级说明
- 为了“高级”而堆相机品牌、8K、HDR、顶级摄影等词
- 同义重复的“真实、专业、电影级、高端、国际级”
- 用户没要求的精确百分比、厘米、灯位
- 大量与当前任务无关的负向禁词
- 给编写者的管理话，如“仔细分析、一次成功、最终可直接复制”

## 4. 主体与动作

一张静态图优先表达**一个动作峰值或一个关系**。

优先写：
`主体 + 动作 + 对象 + 结果`

例如：
- 女模特闭眼微笑，香水贴在脸颊旁。
- 小孩双手抱住巨大玩偶，身体被玩偶遮住一半。
- 产品悬在透明水面上，倒影完整可见。

只有复杂接触容易出错时，才补支撑、遮挡、重心、手别等细节。

人物一致性、多视图、严格体型复用读 `person-identity.md`；普通一次性人物不自动展开完整五官参数。

## 5. 商品与参考图

真实商品以参考图和已确认事实为真源。

普通商品图只写当前视角真正需要的：
`外形/比例 + 关键颜色/材质 + 标签面 + 人物接触关系`

不要把整份商品规格复制进Prompt。只有商品经常变形、角度复杂或品牌结构必须严格一致时，读取 `product-preflight.md` 和相关专项文件展开。

多张参考图要先在后台分清：谁负责身份、商品、空间、动作/构图、风格。最终Prompt只写冲突时需要明确的真源，不写内部分析过程。

## 6. 构图与相机

默认优先使用能直接成像的简词：
- 特写 / 极近景 / 中景 / 全景
- 低机位 / 俯拍 / 眼平
- 大胆裁切 / 大面积留白 / 主体靠边 / 前景压迫 / 对称构图

不要自动把“高级感构图”拆成“三角构图 + 60%–70%主体占比 + 85–105mm + 一侧负空间”。

只有以下情况才写精确相机信息：
- 参考复刻
- 明确透视问题
- 多人空间关系
- 产品边缘畸变
- 用户指定镜头语言

空间连续、多角度、反向机位任务读 `scene-angles.md` / `visual-decision-principles.md`；普通单图不自动建立复杂拓扑。

## 7. 光线、色彩与质感

光影先在后台读 `lighting-and-imaging.md`，最终Prompt通常只保留：
- 1 条主曝光/主光方向
- 1 条关键肤色或材质结果
- 必要时 1 条色彩基调

例如：
`明亮白色高键棚拍，柔和正侧光，深肤色通透有层次，玻璃边缘有干净高光。`

不自动写大型柔光箱角度、辅光比例、焦段、动态范围等参数，除非当前任务真的依赖它们。

材质写可见结果，不堆设备词：
- 皮肤：自然纹理、轻微毛孔/小痣/肤色不均
- 玻璃：透明、折射、边缘高光
- 金属：清晰反射、边缘亮线
- 布料：垂坠、褶皱、粗糙/丝滑

## 8. 文字与版式

用户要文字时只锁：
`准确文案 + 颜色 + 大小/显著程度 + 大致位置/留白关系`

例如：
`白色留白区放明显深蓝英文标题“BLUE VEIL”，简洁高端杂志排版。`

不要自动加入多组副标题、装饰线、小字和品牌文案。准确文字需要可靠资产时优先保留参考或为后期合成留干净区域。

## 9. 负向提示

负向项按**风险触发**使用，通常 2–5 项足够。

优先只防：
- 当前产品结构变形
- 人手/接触关系错误
- 皮肤过度塑料化
- 文字乱码
- 当前画面最容易发生的曝光/背景错误

正向已经说清的内容不再全部反写。没有明显风险时可不写负向栏。

## 10. Prompt Pollution Audit

交付前逐句检查：

1. 这句话是否直接改变画面？
2. 是否和前文重复？
3. 是否只是把一个有效概念解释得更长？
4. 是否把模型本可自由完成的审美锁成机械模板？
5. 是否属于当前任务真实风险？

如果答案是“没有改变结果 / 重复 / 只是显得专业”，删除。

最终目标：

> **核心意图明确，关键事实准确，外围实现自由。最少词，最强画面。**
