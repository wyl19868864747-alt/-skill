# 林枫生图提示词框架｜High-Signal Prompt Compiler

本文件定义生图提示词的默认编译方式。目标不是“写得完整”，而是：**用最少、最精准的词，让主体最清楚，只补真正会改变结果的信息。**

## 0. 核心DNA

`保留强意图 → 锁必要事实 → 主体优先 → 最小补充 → 按需真实性修正 → 污染审计 → 输出`

四条总原则：

1. **主体优先。** 人物/产品是谁、长什么样、正在做什么，信息权重默认高于光影、设备和摄影术语。
2. **锁结果，不锁过程。** 先写最终想看到什么，不为显得专业自动规定焦段、比例、灯位、三角构图等实现方式。
3. **专业知识放后台。** 相机、光影、材质、空间、产品与人物知识用于判断，不等于全部进入Prompt。
4. **每句话都要有画面价值。** 删除后画面、动作、关系、光色、材质、文字或物理结果不变，就删除。

## 1. 用户原始意图优先，但抽象目标先转译

用户已经给出高信号、可直接成像的表达时，尽量保留原表达或轻微整理，不把一句有效指令扩写成说明书。

高信号例子：
- 香水贴脸
- 闭眼自然笑
- 极近景
- 白色背景
- 蓝色大字
- 自然皮肤瑕疵
- 巨大前景压迫人物
- 产品完整清晰

这些词已经直接改变画面，不需要继续解释“脸向产品倾斜多少、手指如何包裹、主体占画面百分之多少”。

但以下词属于**创意目标，不直接承担生成指令职责**：
`强钩子、高能、高级感、电影感、张力、情绪感、视觉冲击、超现实感、大片感`

先由Skill完成设计，再压成可见结果：
- `视觉冲击` → 尺寸反差、主体占位、突然视觉事件、大胆裁切；
- `高级感` → 留白、色块关系、版式克制、关键材质控制；
- `超现实感` → 明确唯一违反现实的视觉规则；
- `电影感` → 只保留当前需要的构图、焦点、色彩、成像或空间结果。

## 2. 默认Prompt格式

### A. 简单单图｜默认

一段自然语言，通常按这个顺序组织：

`主体/产品 + 核心动作/状态；场景/构图；必要视觉特征；按需1条真实性/光影修正；少量高风险限制。`

示例结构：

```text
25岁高颜值欧美女性，黑色长发，自然妆容，手持透明香水瓶贴近脸侧，闭眼轻笑。胸像特写，人物靠左，右侧大面积纯白留白，黑发与蓝色英文形成清晰色块关系。玻璃瓶边缘保持透明折射，高光不过曝成白块。避免产品变形、塑料皮肤、英文乱码。
```

重点：不是固定模板，而是**最多只保留当前图真正需要的信号**。

### B. 中等复杂图

必要时分 2–4 个短块：

```text
【主体/关系】
【场景/构图】
【必要视觉】
【必要锁定/风险】
```

没有内容的块直接省略，不为了格式补废话。

### C. 高控制任务

只有以下任务才启用结构化详细字段：
- 跨图人物一致性
- 严格商品复刻
- 多主体复杂接触
- 场景拓扑/多角度
- 四视图/角色设定
- 局部编辑且保留区很多
- 用户明确要求完整参数化Prompt

旧24字段保留为**后台检查表**，不再作为普通单图默认外显格式。

## 3. 信息价值判断

任何新增信息先过三档：

### 高价值｜默认保留
- 主体是谁/产品是什么
- 最关键动作/关系
- 产品/身份真源
- 一个核心构图意图
- 明显影响结果的背景/色彩/文字
- 当前唯一最重要的真实性修正（如果确实有风险）

### 情境价值｜按需
- 主光/曝光关系
- 材质细节
- 焦段
- 精确机位
- 灯具/角度
- 主体占比
- 景深细节
- 前中后景拆分

只有它们能解决当前画面问题时才写。

### 低价值｜默认删除
- 第一/第二/第三视觉层级说明
- 为了“高级”而堆相机品牌、8K、HDR、顶级摄影等词
- 同义重复的“真实、专业、电影级、高端、国际级”
- 用户没要求的精确百分比、厘米、灯位
- 大量与当前任务无关的负向禁词
- 给编写者的管理话，如“仔细分析、一次成功、最终可直接复制”

## 4. 主体与动作

一张静态图优先表达**一个动作峰值或一个关系**。

优先写：
`主体 + 动作 + 对象 + 结果`

例如：
- 女模特闭眼微笑，香水贴在脸颊旁。
- 小孩双手抱住巨大玩偶，身体被玩偶遮住一半。
- 产品悬在透明水面上，倒影完整可见。

只有复杂接触容易出错时，才补支撑、遮挡、重心、手别等细节。

人物一致性、多视图、严格体型复用读 `person-identity.md`；普通一次性人物不自动展开完整五官参数。

## 5. 商品与参考图

真实商品以参考图和已确认事实为真源。

普通商品图只写当前视角真正需要的：
`外形/比例 + 关键颜色/材质 + 标签面 + 人物接触关系`

不要把整份商品规格复制进Prompt。只有商品经常变形、角度复杂或品牌结构必须严格一致时，读取 `product-preflight.md` 和相关专项文件展开。

多张参考图要先在后台分清：谁负责身份、商品、空间、动作/构图、风格。最终Prompt只写冲突时需要明确的真源，不写内部分析过程。

## 6. 构图与相机

默认优先使用能直接成像的简词：
- 特写 / 极近景 / 中景 / 全景
- 低机位 / 俯拍 / 眼平
- 大胆裁切 / 大面积留白 / 主体靠边 / 前景压迫 / 对称构图

不要自动把“高级感构图”拆成“三角构图 + 60%–70%主体占比 + 85–105mm + 一侧负空间”。

只有以下情况才写精确相机信息：
- 参考复刻
- 明确透视问题
- 多人空间关系
- 产品边缘畸变
- 用户指定镜头语言

空间连续、多角度、反向机位任务读 `scene-angles.md` / `visual-decision-principles.md`；普通单图不自动建立复杂拓扑。

## 7. 真实性补丁｜默认最多1条

完成主体、动作、场景和构图后，再问：

`这张图最可能出现的一个AI错误是什么？`

只有答案明确时，补一条最短可见结果；没有明显风险就不补。

示例：
- 漂浮 → `瓶底贴住桌面，底缘保留轻微接触阴影。`
- 玻璃塑料感 → `玻璃边缘保持透明折射，高光不过曝成白块。`
- 金属廉价 → `金属反射连续，避免大片塑料白光。`
- 焦点混乱 → `双眼清晰，背景自然退焦。`
- 空间扁平 → `前景遮挡明显，中景主体清楚，远景细节降低。`
- 人景脱节 → `环境主色只轻微影响朝向光源的一侧。`

不要把接触阴影、反弹光、高光滚降、空气透视、景深、运动模糊全部打包。

## 8. 光线、色彩与质感

光影**不是普通生图的固定字段**。

只有以下情况才读取 `lighting-and-imaging.md` 并向最终Prompt写光：
- 光线决定脸或产品是否可读；
- 产品材质/透明度/反光就是当前卖点；
- 用户明确要求特定摄影/灯光效果；
- 当前问题就是过曝、死黑、脏灰或环境脱节。

需要时优先一条可见结果，例如：
`窗外柔光从右侧照到脸颊，暗侧仍保留轮廓。`

不要默认写大型柔光箱角度、辅光比例、焦段、动态范围等参数。

材质也只写当前关键结果：
- 皮肤：自然纹理/肤色层次
- 玻璃：透明/折射/边缘高光
- 金属：连续反射/边缘亮线
- 布料：垂坠/褶皱/粗糙或丝滑

## 9. 文字与版式

用户要文字时只锁：
`准确文案 + 颜色 + 大小/显著程度 + 大致位置/留白关系`

不要自动加入多组副标题、装饰线、小字和品牌文案。准确文字需要可靠资产时优先保留参考或为后期合成留干净区域。

## 10. 负向提示

负向项按**风险触发**使用，通常 2–5 项足够。

优先只防：
- 当前产品结构变形
- 人手/接触关系错误
- 皮肤过度塑料化
- 文字乱码
- 当前画面最容易发生的曝光/背景错误

正向已经说清的内容不再全部反写。没有明显风险时可不写负向栏。

## 11. Prompt Pollution Audit

交付前逐句检查：

1. 这句话是否直接改变画面？
2. 是否和前文重复？
3. 是否只是把一个有效概念解释得更长？
4. 是否把模型本可自由完成的审美锁成机械模板？
5. 是否属于当前任务真实风险？
6. 光影/设备/材质是否开始比主体和动作更长？
7. 是否仍把“高级感、电影感、视觉冲击”等抽象目标直接丢给模型？

如果答案是“没有改变结果 / 重复 / 只是显得专业”，删除。

最终目标：

> **主体最清楚，核心意图明确，关键事实准确，外围实现自由。最少词，最强画面。**
