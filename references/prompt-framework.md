## 0. 大脑—执行器分工与 Prompt Pollution Gate

把当前编写模型视为“视觉大脑”，把图片生成模型视为“像素执行器”。视觉大脑负责检索、核实、归类、比较、审美判断、参考拆解和理解用户的幕后要求；像素执行器只接收已经转译完成、能够直接改变主体、构图、空间、光线、色彩、材质、文字或物理关系的指令。

以下内容默认不进入最终生图提示词：

- `一次生成即可交付、不需要后期、请仔细分析、最终可直接复制`等给编写者的工作要求；
- 投放策略、目标受众研究、审核流程、选择理由和风险解释；
- `高级、年轻、真实、电影感、TikTok感、像某平台、不要廉价感`等尚未拆解的抽象标签；
- 要求图片模型自行查找、理解、参考或归纳某个平台、趋势、导演、影片、品牌或艺术风格。

抽象风格必须先由视觉大脑研究或拆解，再转译为当前图片所需的可见特征：主体年龄能量与姿态、相机位置与透视、构图密度、光源方向与软硬、主辅色关系、材质反射、清晰度分配、背景频率和后期处理。来源名称最多出现一次用于辅助定位；删除来源名称后，剩余提示词仍须足以复现目标视觉。

每句话都通过污染测试：删除后若主体、动作峰值、构图、相机、空间、光线、色彩、材质、可见文字和物理关系完全不变，即为无效文字并删除。用户明确要求的像素尺寸、画幅、准确可见文字和工具控制语法属于执行参数，可以保留；高风险错误只放入精简负面项。

光影与成像细则唯一归属 `lighting-and-imaging.md`：每次新生成、完整重写和光影返修先读取，再填入本文件已有光影字段；不新增字段、不改顺序。下文的明暗与质感建议是基础方向，用户明确媒介优先。

【材质/纹理】

## 2. 风格选择

每张图只选一个主风格：

| 输入信号 | 主风格 | 核心目标 |
|---|---|---|
| 电影感、真人、实拍、摄影、胶片、剧照 | 真人电影感 | 真实曝光、柔和解析、自然皮肤、干净暗部 |
| 动漫、二次元、动画、插画、手绘、Q版 | 动漫插画 | 通透上色、干净色块、清楚轮廓、受控高饱和 |
| 电商、产品、商品、白底、详情页、海报 | 电商产品 | 结构准确、材质真实、边缘干净、自然投影 |

用户未指定时：真实人物、建筑、街道与自然场景默认真人电影感；幻想、校园、魔法和可爱角色默认动漫插画；明确商品展示默认电商产品。

不要混写“真人实拍皮肤”和“纯二维动漫线稿”等互斥目标。混合风格必须由用户明确指定，并说明主次比例。

## 3. 相机与空间

### 镜头角度

- 低角度：强调力量、权威、威胁或神圣感。
- 高角度：强调脆弱、受困、孤独或被监视。
- 眼平：自然、亲近、叙事中立，适合人物关系与产品真实使用。
- 过肩：跟随、观察、窥视，适合对话和悬疑。
- 贴地低机位：紧张、不稳定，适合巨大主体、追逐和灾难。

角度必须写“摄像机在哪里、朝哪里拍、主体如何朝向”，不能只写情绪形容词。

### 焦段与画幅

- 14–24mm 超广角：强透视、主观冲击、空间夸张；容易使脸和产品边缘变形。
- 24–35mm 广角：环境关系强，适合街道、室内空间、多人站位。
- 35–50mm 标准：接近自然观看，适合克制叙事和真实人物。
- 85–135mm 中长焦：压缩背景、突出人物，适合情绪近景和凝视。
- 200mm 以上长焦：压扁空间、强化监视和围困感。

同一字段只保留一个焦段或窄范围。写明横版/竖版和比例；比例缺失且会影响构图时再询问。

### 景别与景深

- 极远景/大全景：人物很小，环境承担叙事。
- 全景：交代人物、道具和空间关系。
- 中景：动作、对话和关系。
- 近景：表情与情绪。
- 特写：手、眼睛、产品结构或关键道具。

浅景深突出主体；深焦用于主体与环境同等重要；极浅景深只用于梦境、回忆或强情绪隔离。必须指出焦点落点及虚化区域。

### 空间心理与拓扑

- 开放空间：自由、孤独、等待、希望。
- 封闭空间：压迫、秘密、危险、无路可逃。
- 垂直空间：权威、敬畏、渺小。
- 对称空间：秩序、仪式、权力、宿命。
- 破碎空间：混乱、恐慌、不稳定。

参考图空间一致性任务先写固定拓扑，再写本轮镜头。使用“北/南/东/西”或稳定锚点时，始终说明画面方向与现实方位的关系，防止“画面下方”被误解为“地面方向”。

只有在主视图场景已经生成或提供，且用户明确要求该场景的多角度、反向机位、正反打或俯视方位图时，才完整读取并执行 `scene-angles.md`。普通场景图仍按本框架生成单张主视图，不自动制作多角度设定板。

## 4. 主体与动作

### 身份和识别锚点

不要只写“一个人、怪物、产品”。写清职业/类型/物种/品类，以及 3–6 个最有辨识度的外形锚点。

需要跨图复用身份、人物母版、多视图、连续分镜或精确重设体型比例时，读取 `person-identity.md` 并先形成人物身份参数卡；已有确认人物直接复用。一次性普通真人肖像只在后台建立紧凑外形锚点并执行。用户已明确授权自由设计或直接生成时补全设计值继续；只有关键未知会影响后续一致性且无法合理判断时才询问。

人物一致性至少拆分：

- 脸型与五官比例
- 发型、发色和发际线
- 年龄感、肤色和体态
- 服装版型、材质与关键装饰
- 手套、鞋、首饰等易丢失附件

真实全身人物还必须锁定头身比、肩胯关系、上下身比例、腿长、腰线、四肢长度、手脚尺度和站姿重心；不能用“身材匀称、比例自然”代替具体关系。

只有用户明确要求生成“人物/角色四视图”或“带面部特写的四视图”时，才完整读取并执行 `character-sheet.md`，把左侧面部母版和右侧三个全身角度视为同一身份的同步视图。普通角色设定、单张定妆照、一般人物资产和场景多视图任务不得套用该专项版式。

产品一致性至少拆分：

- 外轮廓与比例
- 正反面、接口和功能结构
- 材质与反射方式
- 包装、标签和颜色区域
- 不得新增或变形的零件

### 材质和细节预算

把高细节集中在脸、手、关键道具或产品表面。皮肤写自然受光与柔和层次，不把“毛孔极清晰”当成真实。黑色服装仍需受光面、褶皱和边缘分离。

### 动作和姿态

一张静态图优先表达一个清晰动作峰值。写出四肢支撑、重心、视线和接触关系。避免同时要求“坐着、起身、回头、伸手”等多个时间阶段。

多人物关系写空间锚点，不只写画面左右。例如：A 坐在餐桌西南位，身体朝东；B 坐在东南位，身体朝西，两人隔桌相对。

## 5. 场景分层

### 场景母图的信息覆盖

场景图若承担后续视频锁景、人物走位、远近景切换或镜头后拉的参考资产，默认选择稍远的完整环境景别，在一张图中尽量呈现主要空间边界、固定家具、关键陈设、出入口、主体活动区域和前中后景关系。目标是让后续模型能够复用已经出现的场景特征，减少画面扩展时随机补全未知区域。

这里的“广角、展示更全”首先是信息覆盖要求，不等于必须使用超广角镜头。优先通过摄影机适度后移、主体占比缩小、减少无意义遮挡和保留周边环境完成；只有确有空间需要时才补充焦段。不要为了显得专业而额外编造房间尺寸、复杂方位、建筑结构或大量相机参数，也不要用强烈透视和边缘畸变换取表面的视野宽度。

场景母图仍需保持明确的核心区域；“展示更多”不是把背景塞满无关装饰，而是让有连续性价值的场景特征进入画面。若用户要的是单个成片近景、商品特写或情绪特写，则不自动扩大景别。

- **前景**：最靠近镜头，可遮挡、框景、制造纵深或提供尺度。
- **中景**：主体与核心叙事关系所在，通常是视觉重点。
- **远景**：出口、天空、城市轮廓、山体、海面等低频信息。
- **背景**：整体环境基底，负责分离主体，不与主体争夺细节。

背景、天空、墙面、地面、草地、人群和烟雾尽量使用大色块与低频细节。不要为了“丰富”而新增无关家具、标识、人群或装饰。

## 6. 光线与色彩

### 光线必须可信

先确定主光源的位置和性质，再安排辅光、反射光和气氛光。避免无来源的随机光柱、粒子和轮廓光。

暗部按当前媒介与画面任务保留层次；需要读清的区域由实际窗光、天空散射或表面反射托起。用户明确选择剪影、深暗部、胶片颗粒或暗光手机噪点时保留其表达，只修不合意的脏斑、结构丢失和干扰主体的噪声。

### 软硬与互动

- 硬光：清晰阴影、强形体，适合正午、聚光、悬疑和力量感。
- 柔光：缓慢过渡，适合人物定妆、家居、电商和温和叙事。
- 半柔光：保留方向性但不过硬，适合大多数电影感室内场景。

互动光必须有可见来源，例如霓虹、火焰、屏幕、水面或浅色墙面。产品摄影优先使用可控柔光箱与自然投影。

### 色彩控制

多数画面使用 2–3 个主色和一个小面积点缀色。真人电影感可低饱和但不能灰成一片；动漫可中高饱和但减少杂色；产品颜色必须准确，避免环境色污染。

分别写清：整体冷暖、主体与背景的饱和度分配、高光色相、阴影色相、对比度和局部对比度。黑色阴影可偏冷蓝灰、暖灰、深棕或深蓝绿，不使用混浊泥灰。

## 7. 质感、细节和负面控制

以下为按失败类型选取的候选，不是每张图必贴的禁令；用户明确的剪影、颗粒、噪点、粗糙手绘和非写实风格优先。先写正向目标，只保留本次实际相关的少量项。


### 真人电影感

可用：真人电影摄影质感、柔和电影镜头解析力、自然细腻银盐颗粒、高光轻微扩散、边缘自然过渡、真实布料纹理、自然皮肤层次。

避免：用 8K、超清、极致细节、sharp focus、ultra detailed、强 HDR 和过度锐化替代摄影逻辑；过度磨皮、塑料皮肤、锐利毛孔也不是真实。

### 动漫插画

使用动画电影级通透上色、干净色块、清楚但不过锐的线条、柔和阴影、较高明度。通过减少杂色和碎纹理解决脏感，不要为了“电影感”把全部颜色降成灰色。

### 电商产品

强调商品结构、边缘、材质反射、准确色彩和自然投影。玻璃看透明度与折射；金属看反射形状和边缘高光；食品看新鲜湿润光泽；服装看面料与垂坠；护肤品看瓶身、液体和标签区域。

文字和 Logo 需要准确时，不要相信纯生成稳定还原复杂文字；优先保留参考资产或为后期合成留出干净区域。

### 负面控制

负面项放入对应字段，只写当前高风险错误：

- 背景高频杂乱、无关物体增生
- 暗部死黑、彩色噪点、颗粒结块、脏灰色块
- 数码过锐、油腻 HDR、塑料皮肤、过度磨皮
- 多余肢体、变形手指、错误接触关系
- 产品零件变形、正反面混乱、包装文字错误
- 主体与背景同色同亮导致粘连

不要列几十条与任务无关的负面词；过长禁止列表会稀释核心约束。

## 8. 常见问题修复

| 问题 | 优先修改 |
|---|---|
| 太脏太乱 | 减少背景元素和碎纹理，保留大色块 |
| 太暗/暗部死黑 | 增加有来源的环境反射光，保留阴影色相 |
| 过白 | 降低曝光或主光强度，明确仍保留自然室内层次 |
| 偏黄 | 减弱暖光比例，引入中性自然光，不直接改成冷白 |
| 噪点太多 | 降低暗部颗粒与彩色杂讯，背景保持低频 |
| 黑色发脏 | 改为明确的冷灰、暖灰或深蓝灰受光层次 |
| 颜色太灰 | 提升主色明度与饱和度，减少杂色和泥灰阴影 |
| 颜色太花 | 限制主色数量，降低无关元素饱和度 |
| 主体不突出 | 建立亮度、色彩、清晰度或位置优势 |
| 太数码太锐 | 使用柔和解析、高光扩散和自然边缘，移除强 HDR |
| 人物不像 | 拆分并强化五官、脸型、发型、年龄与服装锚点 |
| 机位不对 | 写摄像机的实际位置、高度、朝向和主体相对关系 |
| 空间错乱 | 先锁拓扑与固定物，再描述可变主体 |
| 产品不高级 | 简化背景，校正反光形状，增加自然投影 |

优先局部改字段。若根因是参考职责、空间拓扑或任务类型理解错误，整体重组提示词。

## 9. 最终检查

- 主体和视觉中心是否明确？
- 相机是否服务情绪并具有实际位置？
- 人物、产品和空间锚点是否稳定？
- 场景母图是否覆盖了后续远近景与镜头扩展所需的主要空间特征？
- 动作是否只表达一个清楚状态？
- 光源是否有来源，互动光是否合理？
- 主色是否克制，主体是否与背景分离？
- 细节是否集中在关键区域，背景是否低频干净？
- 暗部是否有层次、无死黑、无彩噪和脏斑？
- 是否避免过锐、伪 HDR、过度磨皮和无关复杂度？
- 最终指令是否为一个确定方案，没有互斥备选？
