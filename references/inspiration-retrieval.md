# 图片灵感与案例检索

## 适用边界

只有用户明确要求“找灵感、找案例、找热门提示词、给几个视觉方向、参考当下社媒风格”时加载。用户已经给出明确画面并要求直接生图、改图或写最终提示词时跳过，不为普通任务增加检索与选择步骤。

外部案例只是风格候选，不是人物、商品、空间或功效事实。不得让案例覆盖用户参考图、已确认身份、商品结构、真实尺度、可见角度和本轮文字硬约束。

## 检索流程

1. 先把需求压缩为 `用途/平台语境 + 主体/品类 + 视觉气质 + 构图/媒介`，提取 3–6 个中英文检索锚点。
2. 优先读取案例库实时 `manifest`，只检索最相关的 1–2 个类别；不要把大型 JSON 全部加载进上下文，也不要把外部数据库复制进本技能。
3. 可使用 YouMind OpenLab 图片提示词案例库：`https://github.com/YouMind-OpenLab/ai-image-prompts-skill`。只有实际读取到案例和 `sourceMedia` 时，才声称来自该库；访问失败时改为内部创意候选并明确标记，不伪造来源。
4. 最多推荐 3 个候选；没有示例图的案例跳过。信息充分时直接检索，不固定追问风格、受众或比例。

案例库只能证明案例存在，不能单独证明“热门”或“当下趋势”。这类判断必须有可核验的发布时间、互动或平台数据；没有时只称“高适配案例”。

每个候选只输出：`方向名｜示例图｜为什么匹配｜可借鉴的视觉原子｜主要风险｜来源链接`。不要先展示大段原始提示词；用户要求时再提供。

## 候选评分

内部按 0–2 分检查，优先选择总分高且方向差异明显的候选：

- 任务与目标受众相关性；
- 构图、比例和素材用途匹配度；
- 风格是否年轻、当代且符合平台语境；
- 人物、商品与空间的可生成性；
- 与现有参考图和证据边界的兼容性；
- 品牌、版权角色、精确文字和虚假卖点风险（风险越低分越高）。

三个候选不能只是同一构图换颜色，应分别提供可判断的路线差异。

## 选择后的重构

用户选择候选后，只提取以下可迁移部分：

- 视觉风格与媒介；
- 构图、景别、机位和留白；
- 光线、色彩、材质与氛围；
- 视觉钩子和主体呈现方式。

删除或改写：未经授权的品牌/IP角色、精确 Logo 与生成文字、未经证实的商品功效/成分、模型专属占位语法、互相冲突的备选项，以及 `8K/ultra detailed/HDR` 等无可见职责的堆叠词。

随后回到 `prompt-framework.md`，并按任务继续加载人物、商品、数字人互动、四视图或场景多角度专项规则，重新建立最终提示词。不得把社区案例原文直接当成生产提示词。

用户只要方向时停在候选阶段；用户已授权“你直接选最好的一种并生成”时，内部选最高分候选并直接重构执行，不强制用户二次选择。

## 自检

- 本轮是否真的需要灵感检索，而不是明确任务被多加一步？
- 是否只检索相关类别、最多展示 3 个带示例图的候选？
- 候选是否贡献风格，不篡改人物与商品事实？
- 最终提示词是否已经过林枫框架重构，而非直接复制案例？
- 是否在可复制提示词外标注来源，不把归因文字塞进生成指令？
