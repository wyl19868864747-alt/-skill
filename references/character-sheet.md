# 带面部特写的角色四视图标准

仅在用户明确要求生成“人物/角色四视图”或“带面部特写的四视图”时读取并执行。用户只要求普通角色设定图、单张定妆照、人物资产图、场景四视图、人物三视图、人物五视图或其他数量的多视图时，不自动套用本标准；按其本轮要求或对应场景模块另行组织。用户明确指定的画幅、风格、角度或版式始终优先。

## 1. 画布与版式

- 默认使用横版 16:9，目标画布不低于 3840 × 2160 px。
- 左侧约 40%：同一人物正面脸部大特写，从头顶到颈部或锁骨上缘完整入画；头部与颈部充分填满左侧视窗，眼睛清晰对焦。
- 右侧约 60%：三个等宽区域依次排列同一人物的正面全身、严格 90° 侧面全身、背面全身。
- 三个全身像等高、等比例、等间距，头顶与脚底分别落在统一水平线上；头、手、鞋完整入画，不裁切。
- 背景为纯净白色无缝影棚；不添加标题、字母、数字、边框、装饰线、道具、地台或无关影子。

除非用户另有要求，“四视图”在本标准中指一个面部特写加三个全身角度，不额外生成第五个人物。

## 2. 唯一身份母版

真人四视图先复用依据 `person-identity.md` 建立的已确认参数卡；参数卡尚未建立时，先完成身份与身材比例确认，再进入四视图版式。

先从用户描述或人物参考图建立唯一身份母版，至少锁定：

- 脸型、颧骨、下颌与下巴轮廓
- 双眼形状、瞳色、眼距、眉形与眉眼距离
- 鼻梁、鼻翼、鼻尖与侧面鼻部轮廓
- 上下唇比例、唇峰、嘴角与自然唇纹
- 发际线、发型、发色、发长与碎发分布
- 年龄感、肤色、肤色冷暖、体型、身高比例与肩胯关系
- 服装版型、领口、袖长、腰线、裤/裙长、面料、图案、缝线、扣件
- 配饰、手套、鞋履及其数量、位置、材质和颜色

明确写：四个画面是同一人物在同一时刻、同一妆发和同一套服装下的同步摄影视角，不是四位相似人物；以左侧面部特写为唯一身份母版，其他视图只改变观察角度。

用户只要求可复制的通用模板、但没有提供人物参考图或身份描述时，保留 `[填写人物身份与五官锚点]`，不要擅自指定性别、族裔、年龄或具体长相。用户要求自由设计或直接生成时，才按整体创意合理补全唯一身份。

## 3. 角度、站姿与表情

- 左侧特写与右侧正面全身均正对镜头，头部端正，不歪头、不倾斜、不做三分之四侧脸。
- 侧面全身为严格 90° 标准侧面，摄像机与人物肩线垂直；不要生成 45° 或三分之四角度。
- 背面全身为严格 180° 背对镜头，头部与躯干同时朝后，不回头。
- 全身像自然直立，双脚自然平行或小幅分开，重心居中，双肩放松。
- 双臂沿身体两侧自然下垂，双手可见、手指自然放松；不插兜、不叉腰、不抱臂、不持物、不遮挡服装结构。
- 保持克制中性表情、闭嘴、自然呼吸感，不夸张微笑，不做戏剧性动作。

## 4. 真人摄影真实感

真人模式优先描述可验证的摄影关系，不堆叠空泛画质词：

- 使用商业棚拍和高级时尚画册质感；全画幅相机的中长焦透视，面部特写约 85–105mm，全身约 70–85mm，眼平机位，无广角拉伸、头大脚小或边缘变形。
- 使用足够景深，左侧双眼、右侧正面脸与服装细节均清晰；不以虚化掩盖五官或衣料。
- 使用 5200–5600K 的中性柔和日光质感：大面积柔光从镜头前上方轻微偏侧照射，弱填充光托起阴影；四个画面曝光、白平衡和光向一致。
- 保留自然面部起伏与柔和明暗过渡；皮肤包含不规则细小毛孔、轻微绒毛、细腻肤色变化和少量真实纹理，但不过度放大毛孔。
- 眼球具有自然湿润高光、真实虹膜层次和轻微巩膜血色，巩膜不是纯白；睫毛、眉毛和发际碎发不机械重复。
- 嘴唇保留自然唇纹与湿润度，牙齿只在确有需要时露出；耳廓、发际线和颈部连接符合真实解剖。
- 服装呈现真实织纹、接缝、锁边、拉链/纽扣结构、受力褶皱和身体接触阴影；不出现纹理熔化、图案漂移或配件增生。
- 后期克制，保持真实动态范围与自然锐度，不使用强磨皮、伪 HDR、轮廓光晕、过强降噪或局部过度锐化。

负面控制仅保留本任务高风险项：禁止变脸、不同人物、年龄漂移、发型变化、换装、服装图案漂移、配饰增删、身体比例变化、45° 假侧面、回头背面、歪头、插兜、叉腰、手脚裁切、五官模糊、塑料皮肤、均匀假毛孔、玻璃眼、纯白眼球、过度磨皮、伪 HDR、过锐白边、广角畸变、多余肢体、手指粘连、漂浮脚、文字和水印。

## 5. 分辨率与 PPI

- 在支持尺寸控制的工具中，设置 3840 × 2160 px 或更高的 16:9 画布；若不支持精确尺寸，选择最高原生横版分辨率，优先保证脸部与三个全身像的可读面积。
- PPI 是文件打印密度元数据，不会凭空增加像素或修复模糊。只有工具或导出流程支持时才设置为不低于 300 PPI；不要在无法验证时宣称已经达到。
- 若用户需要印刷交付，先确保实际像素满足印刷尺寸，再在无重采样或受控放大的导出阶段写入 300 PPI 元数据。
